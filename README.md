# Wooblay

Software and AI systems engineer building products across backend,
infrastructure, agent tooling, distributed systems, and physical systems.

I like work where the boundaries matter: software meeting operators, agents
meeting real permissions, and autonomy meeting real hardware.

## Selected work

- **[Wooblay](https://github.com/RealWooblay/WooblayAI)** - an execution firewall
  for AI agents, with policy gates, isolated credentials, human approval, and a
  tamper-evident audit trail.
- **[Bubble Wars](https://github.com/RealWooblay/bubblewars)** - a
  hackathon-winning collaborative on-chain Telegram strategy game combining
  verified user identity, referrals, randomised raids, indexed state, and a
  trusted AI runtime.
- **[Frontier Rover](https://github.com/RealWooblay/frontier-rover)** - a measured
  robotics apprenticeship focused on embedded Linux, sensing, control, safety,
  and reliable autonomous systems.
- **[Stables Yield Optimiser](https://github.com/RealWooblay/stables-yield-optimiser)**
  - real-time Solana yield intelligence with risk-adjusted strategy ranking,
  leverage simulation, and portfolio optimisation.
- **[Prove Me Wrong](https://github.com/RealWooblay/prove-me-wrong)** - an
  AI-assisted prediction-market prototype spanning browser extension UX,
  evidence-based resolution agents, and Solidity settlement.
- **[USX Agent Pong](https://github.com/RealWooblay/usx-agent-pingpong)** -
  autonomous agents that settle game outcomes through Claude tool use, Jupiter
  swaps, Solana transfers, and live transaction state.
- **[Solstice Pay](https://github.com/RealWooblay/solstice-pay)** - a mobile-first
  stablecoin payment prototype built around embedded wallets and human-readable
  recipients.
